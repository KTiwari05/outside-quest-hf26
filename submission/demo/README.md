# Demo evidence

`outside-quest-walkthrough.webm` is a silent browser recording of the planner,
real generated neighborhood activity, takeaway view, text download, and mobile
takeaway. The activity was generated before recording; the 45.74-second inference
wait is not shown. The video runs for 22.33 seconds. The recording does not simulate a new model call or an outdoor
trial. It was captured with Playwright CLI at 1360 x 1000 and 15 frames per second.

The screenshots show desktop and 375px mobile views. The model text is genuine
local Qwen output; screenshots are not mockups.

Upload the walkthrough to an accessible host before adding its URL to the DEV
post. Local paths are for review and do not satisfy the public demo link requirement.
