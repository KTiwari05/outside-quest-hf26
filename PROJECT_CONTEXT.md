# Outside Quest

Started October 7, 2026 as a new local repository for Hacktoberfest Week 1.
Theme: Touch Grass. Official deadline: October 12, 2026, 12:29 PM IST
(October 11, 2026, 11:59 PM PDT).

User authorized building the proposed minimal project. The workflow is time budget,
surroundings, and pace -> local open-weight AI -> three steps and one reflection
-> takeaway view or downloadable text. Keep scope small.

Stack: React + Vite, FastAPI, httpx, uv, Ollama, Qwen3 4B. No database, login,
GPS, maps, route generation, RAG, agents, analytics, payments, or paid inference.
Balcony always requests staying in one spot. Structured JSON is validated.
Do not silently replace failed AI calls with preset activities.

Frontend dev: port 5174, API: port 8001. Built UI is served by the backend at `/`.
See README for setup. Local serving does not establish public deployment.

Read submission/VERIFICATION.md for current evidence. Outdoor testing, personal
feedback, public hosting of source/demo, DEV publication, challenge registration,
and sticker credit must each be established separately. Do not invent these claims.
The DEV file is a local draft, not a submission. It has the Week 1 template and tags.
